# SDC Lab — Java Development Workspace

## Overview

This workspace contains the SDC (Software Development Construction) lab assignments implemented in Java. The repository is organized so each lab can have its compiled binaries, libraries, and source code separated for easy compilation and execution.

This README documents the folder structure, how to get started, how to compile and run the lab programs, and notes about the key source files.

## Getting started (Windows)

Prerequisites

- Java JDK 11 or later installed and `java`/`javac` available on `PATH`.

Quick compile & run (command line)

1. Open Command Prompt and change directory to the workspace root, for example:

```powershell
cd "C:\Users\H-ali\Desktop\SDC_Lab"
```
